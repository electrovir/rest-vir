      ): Promise<EndpointFetchStreamOutput<Endpoint, Method>>

      Send a request to an endpoint definition and return a ReadableStream instead of parsing the response body. Useful for consuming SSE (Server-Sent Events) endpoints from the frontend.

      Uses the same request-building flow as .fetch(), but skips response body and JSON validation.
